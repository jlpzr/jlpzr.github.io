# Control de cambios

Registro interno de cambios del repositorio. Este archivo se excluye del sitio
generado y no forma parte de las páginas publicadas.

## 2026-11-17

- Se añadió una animación de parpadeo al guion bajo del logo, respetando la
  preferencia del sistema por movimiento reducido.
- Se creó este registro de cambios para documentar futuras modificaciones.
- Se añadió `/privacidad/` como índice de políticas, enlazado desde la navegación
  y con la política actual de Cotizame.
- Se unificó el diseño de la política de Cotizame con la identidad visual y la
  navegación de Xanders.

## 2026-11-18

- Se corrigió el efecto del titular a máquina de escribir: las letras aparecen
  una a una y el guion bajo `_` sigue el texto mientras se escribe. El texto
  completo permanece visible sin JavaScript y la animación se desactiva con
  movimiento reducido.
- Se ajustó el cursor del titular para que avance con cada letra en lugar de
  quedar fijo en la primera posición. Queda a la derecha de la letra recién
  escrita y simula el cursor de un editor durante la entrada.

## 2026-11-19

- Se agregó el enlace oficial de Facebook al bloque de contacto de la portada.
