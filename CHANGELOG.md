# Control de cambios

Registro interno de cambios del repositorio. Este archivo se excluye del sitio
generado y no forma parte de las páginas publicadas.

## 2026-11-17

- Se añadió una animación de parpadeo al guion bajo del logo, respetando la
  preferencia del sistema por movimiento reducido.
- Se creó este registro de cambios para documentar futuras modificaciones.
- Se añadió `/privacidad/` como índice de políticas, enlazado desde la navegación
  y con la política actual de Cotizame.
- Se unificó el diseño de la política de Cotizame con la identidad visual y la
  navegación de Xanders.

## 2026-11-18

- Se añadió una animación de escritura letra por letra al titular principal. Una
  línea guion bajo parpadea mientras cada línea está en progreso y desaparece al
  terminar. El texto completo permanece visible sin JavaScript y la animación se
  desactiva con movimiento reducido.
